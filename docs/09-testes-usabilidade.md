# Testes de usabilidade e compatibilidade

Roteiro curto para a equipe validar o site estático do NAP. Preencher as tabelas após cada sessão.

**Ambiente:** abrir `index.html` no navegador (ou URL do GitHub Pages, quando houver).  
**Pré-requisito:** CSS/JS carregando (`css/style.css`, `js/main.js`).

---

## Roteiro de tarefas (5–10 min por pessoa)

1. Na **Início**, entender o que é o NAP e ir para Contato pelo CTA.
2. Abrir **Serviços**, ler “Como ser atendido” e chegar em Contato.
3. Em **Conteúdos**, ler uma orientação.
4. No celular (ou DevTools ≤720px): abrir o menu, navegar para Sobre, fechar com Escape.
5. Usar **A+**, **A−** e **Contraste**; confirmar que a preferência permanece ao recarregar a página.
6. Navegar só com **teclado** (Tab / Enter / Escape) por uma página completa.

Critério de sucesso por tarefa: concluir sem ajuda do aplicador e sem erro de caminho.
