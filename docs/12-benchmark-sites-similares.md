# Benchmark — sites de núcleos de apoio similares

Análise **estrutural** de referências públicas (Fase 1). Não copiar textos, imagens nem identidade visual. Usar só para inspirar organização de informação e boas práticas de acolhimento/acessibilidade.

**Como preencher:** abrir cada URL, anotar seções e o que funciona bem para o nosso mapa ([05-mapa-do-site.md](05-mapa-do-site.md)).

---

## Critérios de observação

- Clareza do “o que é / para quem”
- Lista de serviços e “como ser atendido”
- Contato (canais, horário, local)
- Conteúdos educativos
- Acessibilidade aparente (contraste, tamanho de texto, navegação)
- Tom acolhedor vs. burocrático

## Síntese comparativa (após preencher a tabela)

| Padrão observado | Como vamos usar no NAP Impacta |
|---|---|
| Home com CTA de contato | Já previsto em `index.html` |
| Serviços + passo a passo | Já previsto em `servicos.html` |
| Contatos explícitos | Pendente dados oficiais (RF-15) |
| Conteúdos curtos | Já previsto em `conteudos.html` |
| Linguagem acolhedora | Manter; validar com NAP |

## Decisões de estrutura (nossas)

- Manter 5 páginas (Início, Sobre, Serviços, Conteúdos, Contato).
- “Como ser atendido” permanece na página Serviços.
- Não incluir login nem agendamento online (fora do escopo).
