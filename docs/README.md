# Documentação do projeto — Página Web do NAP

Documentação de requisitos e acompanhamento do projeto de extensão **Página Web do Núcleo de Apoio Psicopedagógico (NAP)** do Centro Universitário Impacta.

Esta pasta contém apenas artefatos em Markdown. O código do site permanece na raiz do repositório.

## Como usar

1. Comece pela [visão e objetivos](01-visao-objetivos.md) para o contexto do projeto.
2. Use [RF](02-requisitos-funcionais.md) e [RNF](03-requisitos-nao-funcionais.md) como referência de aceite.
3. Consulte o [escopo](04-escopo.md) antes de propor novas funcionalidades.
4. Acompanhe o progresso na [análise de gap](07-analise-gap.md).
