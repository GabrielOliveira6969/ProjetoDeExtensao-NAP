Esta pasta contém artefatos em Markdown. O código do site permanece na raiz do repositório (`*.html`, `css/`, `js/`, `img/`).

## Como usar

1. Visão e requisitos: `01`–`05`.
2. Progresso: `06`–`07` (atualizar a cada entrega).
3. Qualidade: `08`–`09`.
4. Campo / design: `10`–`13`.
5. Sem dados oficiais: manter placeholders; ao receber dados, seguir `17`.

## Regra de sincronia

Cada entrega de código deve atualizar os checklists em `06` e o status em `07`. Mudanças de comportamento atualizam `02` / `03`.
