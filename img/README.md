# Pasta `img/` — assets visuais do NAP

Reservada para imagens e ícones do site (logo, ilustrações de acolhimento, ícones de serviços).

## Regras

- **Não** adicionar imagens inventadas da marca Impacta/NAP sem aprovação institucional.
- Preferir formatos leves: SVG (ícones) ou WebP/PNG otimizado (fotos).
- Toda imagem **informativa** no HTML deve ter `alt` descritivo em português (RF-18).
- Imagens **apenas decorativas** usam `alt=""`.
- Evitar texto importante só dentro da imagem; o conteúdo principal deve estar no HTML.
